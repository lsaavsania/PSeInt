# Ejercicios de PSeInt

Repositorio con **20 ejercicios resueltos en PSeInt**, diseñados para practicar de manera progresiva los fundamentos de la programación y el pensamiento computacional.

Los archivos utilizan la extensión `.psc` y pueden abrirse directamente con **PSeInt**.

## Objetivo

Practicar la construcción de algoritmos mediante el uso de:

- Entrada y salida de datos.
- Variables y operaciones aritméticas.
- Estructuras condicionales.
- Estructuras repetitivas.
- Contadores y acumuladores.
- Comparaciones y toma de decisiones.
- Resolución de problemas mediante pseudocódigo.

## Requisitos

Para ejecutar los ejercicios se necesita:

- **PSeInt**
- Sistema operativo Windows, Linux o macOS compatible con PSeInt.

PSeInt es una herramienta educativa que permite escribir y ejecutar algoritmos utilizando pseudocódigo.

## Cómo utilizar los archivos

Abrir el archivo, por ejemplo Ejercicio01.psc.
En la vista del archivo, hacer clic en el botón Download raw file o en los tres puntos y elegir Download.
El archivo .psc se descargará directamente y luego podrán abrirlo con PSeInt.

Los ejercicios avanzan desde algoritmos secuenciales sencillos hasta problemas que requieren decisiones y repeticiones.

### Algoritmos secuenciales

Se practican operaciones básicas, lectura de datos, cálculos y presentación de resultados.

### Estructuras condicionales

Se utilizan instrucciones `Si`, `SiNo` y condiciones anidadas para que el algoritmo pueda tomar decisiones.

### Estructuras repetitivas

Se emplean principalmente:

- `Para`
- `Mientras`

Estas estructuras permiten procesar varios datos y repetir acciones sin escribir las mismas instrucciones múltiples veces.

### Contadores y acumuladores

Varios ejercicios utilizan variables para contar elementos o acumular valores durante la ejecución del algoritmo.

## Uso educativo

- Pensamiento computacional.
- Fundamentos de programación.
- Algoritmos y pseudocódigo.
- Introducción a PSeInt.

Los ejercicios están organizados para facilitar la práctica progresiva de los conceptos fundamentales antes de trabajar con un lenguaje de programación.
